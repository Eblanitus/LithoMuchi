## Граф и производительность

CI `42476897293` на `60cd55a` успешно применил настоящие Horizon mixins и собрал core и world. В core отдельно сопоставлены три внедрённых I2-шума с `GameFields`, включая реальные объявленные пределы графа; world загрузил пак и данные 26.3, проверил диапазоны и `depth = gradient + offset`. Игра, фактическая поверхность и LOD не проверены.

Экспериментальный кэш теперь при первом запросе I2 заполняет и обычные поля той же колонки из одной гидрологической пробы; если обычное поле было первым, I2 всё ещё требует расширенного перерасчёта. Порядки запросов проверены побитно. На одном локальном release-прогоне `bench-i2` (16×16 колонок, 9 проходов), до/после: I2-first холодный 0,771/0,521 с, fields-first холодный 0,767/0,773 с; повторные проходы 0,036/0,037 с. Это единичный искусственный тест, не бенчмарк игры, не проверка памяти и не выполнение бюджета.

```bash
cargo run -p litho-sandbox --release -- bench-i2 --version v1-dev --seed 42 --mode gameplay
```

## Локальные соседние блоки I2

`seams-i2` измеряет непосредственно I2 offset, factor/5, jaggedness/1,2 в соседних блоках; нормированный порог 0,02 (для offset это 2,56 блока номинальной высоты). Старый берег C∈[−0,28; −0,10] дал скачок offset 0,06460 на сиде 99999: номинальная высота изменилась на 8,27 блока за один блок. Расширение сглаживания до C∈[−0,60; 0,20] снизило локальный максимум. Повторные пробы: 16 стандартных сидов и сид автора × 2 режима, окна 64² с шагом 16 вокруг начала, плюс пять дополнительных окон gameplay; максимумы offset 0,01879 (seed 1 около озера), factor/5 0,00794, jaggedness/1,2 0,00732. Эти выборки проходят порог, но не доказывают глобальную непрерывность. Таблица гипсометрии выше пересчитана после изменения берега; seed 1 gameplay имеет медиану 9,59 (< цели 10), несколько scientific — менее 6.

```bash
cargo run -p litho-sandbox --release -- seams-i2 --version v1-dev --seed 99999 --mode gameplay --size 64 --bpp 16
```

Научный прототип экспериментально опущен на 4 блока, а длина шума детали снижена с 500 до 450 блоков: авторская локальная доля 63–70 выросла с 16,4 до 33,7%, но y<63 выросла с 0 до 0,3%, медиана лишь 5,96, доля почти плоских окон 32,6%, а другие диапазоны не достигают целей. Это выборка номинальной 2D-формы, не оптимизация по реальному миру; без 3D и больших территорий итоговые последствия неизвестны. Повторная локальная проверка швов 17 научных сидов прошла нормированный порог 0,02.
