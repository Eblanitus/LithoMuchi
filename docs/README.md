## Известные открытые пункты

Не регрессии шагов 1–2, а незакрытая работа по §8, 10.1 и 12.4:

- приёмочный объём 10.1: сетка границ ≥ 200 L с шагом ≤ 32 блоков, 0 из 32 прогонов;
- «климат влияет на форму» 0/16, «озёр на 100 L² суши» 0,02–0,06 при цели ≥ 1,
  скачок влажности по меткам биомов 0/16 (Д-066: приёмка считается по полю H);
- T123 в полном виде (совместная правка полос E и `land_y`, Д-069), холодные
  пруды T114 и R2/T143/T145, длинные реки и ширина вниз по течению (T112/T113);
- ориентиры 12.4 частично вне цели, вердикт в `acceptance` не вынесен; открыты
  поперечники плит, зональный профиль, асимметрия берегов, дождевая тень,
  островная пыль;
- цель 16 мс/чанк не согласована, `enforce_in_ci` выключен, замер 14.4 против
  ванили и проверка LOD в игре не сделаны;
- тесты №3/№4 в игре, релиз и тег; «плоская стена» и меза рядом со льдом из
  [issue #7](https://github.com/Eblanitus/LithoMuchi/issues/7) не проверены;
- R2/вода выше моря и T142/T143 перенесены в v1.1; E4 и доля сухих котловин
  выше целей, извилистость русел ~1,038, мелкий рельеф scientific низкий.
