Единицы T111 — `мм·L²/год`, не м³/с. Кольцо чужой плиты передаёт воду, но не добавляет локальный сток. На зеркале впадины приход считается как дождь `P·h²`, потеря — `PET·h²`; сухой сток `P-k_et·PET` там повторно не вычитается. Стартовые `climate_step_l=1.0`, `et_factor=1.0` записаны только в ключи `v1-dev`. Порядок накопления топологический; среди готовых узлов — по убыванию заполнения f, ничьи по номеру.

T112 переводит блочные стартовые ширины в L через масштаб режима: gameplay 4–28 блоков, scientific 6–60; `Q_min=25 мм·L²/год`, глубина 1.5/2.0 блока, долина ×5 на равнине и ×2 в горах. Меандры: `λ≈11·2w`, амплитуда `1.5·2w` на равнине и `0.3·2w` в горах; концы цепочки закреплены, чтобы слияния не разъезжались. Корзины 0.5 L — инфраструктура запроса, не параметр мира. Пока запрос ищет только сеть ближайшей плиты; 22 конца на кольце соседей в замере ниже ожидаемы до T113 и не выдаются за устья.

Сеть пока использует `e_route = e_km`: потенциал рельефа A появится в T120. Замкнутая область с избытком воды получает статус `ClosedSurplus`, а не фиктивный выход; T113/T114 свяжут её с соседями или уточнят контур. `spill_km` заполненной впадины включает ε-наклон priority-flood; точное зеркало воды — T145. Кэш инфраструктурный (64 плиты), вытеснение не меняет ответ. Новые ключи `drainage.*` входят только в canonical_text `v1-dev`; замок v0 не тронут.

## Предпросмотр высоты

```bash
# Настоящие данные: путь к распакованной копии игры, где есть
# data/minecraft/worldgen/density_function/overworld/{offset,factor,jaggedness}.json
cargo run -p litho-sandbox --release -- render \
  --seed 42 --mode gameplay --version v1-dev --layers vanilla-height \
  --size 256 --bpp 32 --path fast --game-data /path/to/game --out out/height

# Метрики на тех же данных
cargo run -p litho-sandbox --release -- stats \
  --seed 42 --mode gameplay --version v1-dev --game-data /path/to/game \
  --span-l 200 --size 256 --relief-size 64 --relief-step 32 --json

# Без игры: только демонстрация CLI и тестов, НЕ приёмка и НЕ ваниль
cargo run -p litho-sandbox --release -- stats \
  --seed 42 --mode gameplay --version v1-dev --synthetic-height --size 64
```

Формула предпросмотра: `y ≈ 63.52 + 128·offset(C,E,PV)`, `PV = 1 − |3·|W| − 2|`. `factor`, `jaggedness` и трёхмерный шум читаются/разбираются, но в эту приближённую формулу не входят. Погрешность — несколько блоков. `blend_alpha` считается как новый мир (1), старая ветвь `blend_offset` не вычисляется. Неизвестные узлы и ссылки дают ошибку, а не молчаливую подмену.

Суша в новых метриках: `C ≥ ocean_c_threshold` и `river < 0.5`. До T114 озёр ещё нет. Окна рельефа — отдельные 4×4 точки с шагом `--relief-step`, только целиком сухопутные. Основная сетка и сетка окон имеют разные шаги, это явно подписано в выводе. Синтетический сплайн помечен в тексте, JSON и подписи PNG; по нему нельзя объявлять достижение целей v1.
