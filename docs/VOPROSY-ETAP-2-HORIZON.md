## Список вопросов

1. **Версия игры** — в лаунчере Horizon у вас Minecraft 26.3? Это значение нужно для поля `"game"` в `horizon-native.json`.

2. **Коммит Horizon** — в лаунчере указан коммит `66f3981`? Это значение нужно для поля `"horizon"` и для `horizon_revision` в `horizon-mixin.toml`.

3. **Название функции генерации чанка** — как называется функция в Horizon, которая создаёт чанк мира? Нужно для секции `[[injection]]` в `horizon-mixin.toml` (в примере `distant_horizons` это примерно `horizon_client::world::generator::generate_chunk`, у вас может быть иначе).

4. **Точки входа (injection targets)** — какие ещё функции Horizon нужно перехватить, кроме генерации чанка? Например: настройки мода, кнопки в интерфейсе, команды, HUD. Это нужно для остальных `[[injection]]` в TOML.

5. **Типы DensityVolume / DensityError** — какие точные имена типов используются в Horizon API для работы с плотностью блоков? Нужно для реализации `add_to_volume` в `bridge.rs` (задача T72 в плане).

6. **Папка для модов** — куда в лаунчере Horizon нужно класть `.hnmod` файл, чтобы игра его подхватила?

7. **Проверка времени чанков** — как в лаунчере Horizon измерить время генерации чанка? Нужно для подтверждения DoD Этапа 3 (рост ≤ 25 % от ванили).

8. **Документация Horizon** — есть ли у вас ссылка на документацию или исходный код Horizon API, где описаны типы и точки входа?

## Как отвечать

Можно ответить списком цифрами (1–8), короткими фразами или прислать скриншоты из лаунчера Horizon. Ответы помогут записать точные значения в `horizon-native.json` и `horizon-mixin.toml`, после чего можно приступать к коду.
