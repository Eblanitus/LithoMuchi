## 2. Что подготовлено в репозитории

- `mod/horizon-mixin.toml.in` — точка №1: cancellable HEAD, `[[module]]`, `[[crate]] dependent = "horizon-core"`, закрепление на `f319701e8c9ab657ff562250b3ba07b2d654e3bc`.
- `mod/glue/noise_hook.rs.in` — помощник, ровно одна приватная функция без атрибутов (иначе 5.4/5.5 отвергнут).
- `mod/glue/litospherity_glue.rs.in` — строгий разбор имени `litospherity:v0/<режим>/<поле>`, реестр `Generator` на `(seed, mode, version)`, `LithoNoise` с `field_column`, `ConstNoise` для smoke-пака. `add_to_volume` **намеренно оставлен комментарием**: заглушка по умолчанию зовёт `get3` для каждой точки объёма и молча даст неверную производительность, а точные типы `DensityVolume`/`DensityError` ещё не сверены.
- `mod/packs/*.in` — шаблоны `pack.mcmeta`, переопределения пяти `overworld/*` и фиктивные определения шумов. `base_amplitude = 4` с запасом накрывает [−1, 1]: граф берёт диапазон из JSON, а не из `range()` экземпляра (5.3).
- `tools/xtask` — `pack`, `bundle`, `bundle-check`: генерирует **три** пака (`v0/scientific`, `v0/gameplay`, `smoke`), собирает папку бандла с копией `crates/litho-core` и проверяет, что все файлы на месте и ни одного `@ПЛЕЙСХОЛДЕРА@` не осталось.
- `.github/workflows/ci.yml` — шаг «Э2 — шаблоны паков и бандла» без `|| true`. Он проверяет **целостность шаблонов**, а не совместимость с Horizon.

**Smoke-пак** (`litospherity_smoke`) — это ровно то, чего требует DoD: все пять
полей ссылаются на `litospherity:smoke/<поле>`, клей возвращает константу,
`continents = 0.8`. Если мир создаётся всюду сушей, точка №1 работает; если
рельеф ванильный — значит помощник не применился или имена шумов не дошли.

## 3. Чек-лист первой сборки на Windows (T70 → T72)

```text
horizon-launcher settings native-profile dev      # пересборка мода ~в 6 раз быстрее
cargo run -q -p xtask -- bundle --out out/bundle  # в репозитории, можно и на Linux
horizon-launcher native-build <папка out/bundle> --instance <имя> --trust-native-code
```

1. Выключить Smart App Control (иначе `os error 4551`, 5.6). Первая сборка 20–30 минут.
2. Записать сюда путь к `horizon-launcher` и дерево папки экземпляра (пункт 6).
3. Открыть `native/build.log`: мод должен примениться, а не исчезнуть с `E_TARGET_NOT_FOUND`.
4. Создать мир с типом **Normal** и только паком `litospherity_smoke`. Ожидание: всюду суша, в логе — наш генератор.
5. Затем мир с `litospherity_v0_scientific`, отдельно с `litospherity_v0_gameplay`. Включить ровно один пак (8.4).
6. Сверить пять ванильных файлов 26.3 и `aquifers.lava` (пункт 2); при расхождении обёртки поправить `mod/packs/density_function.json.in`.
7. Сверить точные пути типов в `litospherity_glue.rs`, реализовать `add_to_volume` по колонкам, проверить `range()` фиктивного определения.
8. Только после 1–7 записать в таблицу выше «ПРОВЕРЕНО» с датой, коммитом Horizon и логом.
