# 11. Глоссарий

- **L** — единица длины на карте мира, 1 L = 1000 блоков в научном режиме [ПО СИТУАЦИИ для геймплея].
- **G** — ячейка семян плит (Вороной), в L.
- **Плита** — область вокруг семени; у плиты есть материк или нет.
- **κ (каппа)** — поле материка: расстояние до берега внутри материка, км-подобные единицы.
- **Граница** — стык двух плит; тип (сближение, расхождение, скольжение) по `Δv` и нормали.
- **φ (псевдоширота)** — 90° у полюса-точки, 0° на экваторе между полюсами
  (`φ0 = 90·(1 − 2t)`, см. [climate.md](climate.md)). Ориентиры — в градусах.
- **Полюс-точка** — центр температурного пояса, одна на ячейку сетки полюсов.
- **T_sl, T_bio** — температура на уровне моря и биотемпература (Холдридж).
- **PET** — потенциальная испаряемость, мм/год (58,93 · T_bio).
- **R** — индекс сухости, PET/P.
- **μ (мю)** — влагосодержание воздуха на точке, безразмерное.
- **Луч влаги** — линия тока против ветра длиной `land_length_l` (32 L).
- **C, E, W, T, H** — пять ванильных параметров (континентальность, эрозия, странность,
  температура, влажность), по которым ваниль строит рельеф и биомы.
- **PV** — «peaks and valleys», производная от |W|, форма рельефа.
- **R2 / вода выше моря** — задача: озёра и реки выше уровня моря (Д-079).
- **I2 / своя высота** — полная подмена высоты через датапак `overworld/offset`.
- **LOD** — дальний рельеф, колонка, упрощённая для больших расстояний.
- **v0 / v1-dev** — версии генератора (см. [modes-and-versions.md](modes-and-versions.md)).
- **Д-0xx** — номер решения в [DECISIONS.md](../DECISIONS.md).
- **T0xx / T1xx** — номера задач плана пересмотра (историческая нумерация).
- **Ориентир 12.4** — ожидаемый диапазон метрики (не гейт); см. [metrics-and-acceptance.md](metrics-and-acceptance.md).
- **Приёмка 10.1** — гейт PASS/FAIL по сетке границ.
- **Песочница** — `litho-sandbox`: программа, рисующая карты и метрики без игры.
