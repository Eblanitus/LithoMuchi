# 8. Режимы и версии

Статус: **верно** по коду (`mode.rs`, `version.rs`) и **по плану** для описания режимов.

## Два режима

| | геймплейный | научный |
|---|---|---|
| Идея | как ванильная генерация, но крупнее | максимально правдоподобно |
| Ячейка плит `G` | 4000 блоков [ПО СИТУАЦИИ] | 16 000 блоков |
| Порог W-знака (`w_sign_half_width_blocks`) | 48 | 96 |
| Шум температуры (`jitter_t_c`) | 1,0 | 0,5 |
| Ориентир | плавный переход, играбельно | 1000 блоков одного биома — нормально |

Выбор режима в меню при создании мира. Режим и версия записываются в мир.

## Версии генератора

- **v0** — заморожена (scientific `5cdbe1d36ef8d16a`, gameplay `b48e8037c4e85977`).
  Не меняется. CI держит замок (Д-026).
- **v1-dev** — текущая разработка (scientific `8887e6a4ec1f7f65`,
  gameplay `c83af97b33674349`, Д-064/Д-065). Меняется, пока не выпущена.
- Выпущенная версия никогда не меняет вывод: иначе между старыми и новыми чанками будут
  швы (план v1.0, 6.8).
