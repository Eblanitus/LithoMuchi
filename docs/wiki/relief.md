# 6. Рельеф и своя высота

Статус: **по плану** (план-пересмотр разделы 6.1–6.7) и **по коду** для шагов 5 и 6.

## Что ваниль делает с рельефом

Высоту строит ваниль из пяти чисел: C, E, W, T, H. Наш мир подменяет эти числа. Этого
хватает для «ванильной» формы рельефа. Ограничения видны на карте: равнины плоские,
горы похожи друг на друга, температура меняет цвет, а не форму.

## Слой форм (T120–T122)

- Форма рельефа берётся из морфоклиматических зон: горы у стыков, равнины, плато, впадины.
- Перевод в E, PV (или |W|) и C — по зонам, а не по одному шуму.
- Гипсометрия по режимам: в научном режиме выше разброс, в геймплейном ниже.
- Температура влияет на форму (не только на цвет): это критерий «климат влияет на
  форму» 10.1. Сейчас 0 из 16 — открыто, см. [../PLAN.md](../PLAN.md), шаг 3.

## Своя высота (полная I2)

**Решено (Д-079):** полная своя высота входит в v1 для обоих режимов. Механизм: датапак
переопределяет `overworld/offset`, `factor`, `jaggedness`. Единицы: `offset = y/128 − 1`.

**Ошибка 2026-11-10 (T144):** ядро давало `offset = (y − 63, 52)/128`, из-за чего всё
было на 64,48 блока выше, океанов не было. Исправлено, подтверждено автором в игре.
