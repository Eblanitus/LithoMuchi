# 3. Климат: полюса, ветер, влага

Статус: **верно** по константам (сверено с `params.rs`), **по плану** по формулам.
Числа в скобках — значения в коде.

## Температура: полюса-точки

- Сетка полюсов `G_P = 64 L`, ровно один полюс в ячейке, отступ 0,1 G_P.
- Псевдоширота: `t = F1/(F1+F2)` по двум ближайшим полюсам, `φ0 = 90·(1 − 2t)`,
  `φ = clamp(φ0 + 3·fbm, 0, 90)`.
- Все полюса одинаковые («северные»). Поэтому ветер на экваторе между полюсами
  получает восточно-западную составляющую, которой на Земле нет (см. ветер).
- Температура на уровне моря: `T_sl(φ) = 28 − 52·(φ/90)^1,6` °C.
- Высота: −6,5 °C на км. Континентальность: в глубине материков теплее в тропиках
  (до +2 °C) и холоднее в высоких широтах (до −6 °C).
- Сезонная амплитуда `A = A_lat(φ)·(0,25 + 0,75c)`: у моря мягко, в глубине резко.
  Нужна, чтобы классы «тайга» и «тундра» не ломались. Сезонов как механики нет.

## Ветер

- Три пояса по псевдоширите: пассаты (0–30°), западные (30–60°), полярные восточные (60–90°).
- Сила `s(φ)`: 0,25 на экваторе (штиль), 1,0 на 15°, 0,3 на 30°, 1,0 на 45°, 0,3 на 90°.
- Ветер — не игровая механика, нужен только для влаги.

**Ошибка** в прежних метриках: «восточные берега пассатов суше западных» считало восток
по оси x мира. Исправлено в Д-080: восточность считается по направлению `ê` модели.
Перемерено: восточные берега влажнее в 1,4 раза (знак верный), но Д-080 фиксирует
асимметрию отношения 0,58–0,76 при ориентире ≥ 2 — не проходит.

## Влага

- Линия тока против ветра: 32 шага по 0,25 L, длина 8 L по плану.
  **В коде (`land_length_l`) 32 L**, в v0 и v1-dev (Д-064: луч 8 L давал пустыни 38 % и
  лес 9 % на 16 сидах). Значит, в плане v1.0 длина луча устарела.
- Перенос влаги по ветру: над морем влага растёт к насыщению, над сушей убывает
  (`ℓ_land = 6 L`), на подъёме в горы теряется `exp(−Δh/h_oro)`, `h_oro = 1,5 км`
  (`orographic_height_km = 1.5` в коде).
- Осадки: `P = P_c(φ)·(a + (1 − a)·μ) + 1500·max(|V|, 0,6)·μ·U`.
  - `P_c(φ) = 1900·exp(−(φ/11)²) + 900·exp(−((φ−50)/13)²)` мм (`itcz_precip_mm`,
    `front_precip_mm`, ширины 11° и 13°, центр 50° — в коде).
  - `advection_mm = 1500` (в коде).
  - `a(φ) = 0,15 + 0,55·exp(−(φ/15)²)`, `local_fraction_base = 0,15` в коде.
- Испаряемость (Холдридж): `PET = 58,93·T_bio` мм (в коде `pet_per_bio_c = 58.93`).
- Индекс сухости `R = PET/P`.

## Ошибка в плане: минимум осадков

**Ошибка.** План v1.0 (ориентир 12.4) ожидал минимум осадков в 20–30°. Замер зонального
профиля (Д-074, `climate124-zonal-1`): максимум в 0–5°, локальный второй максимум в 45–55°,
а глобальный минимум в 80–85°. Так и на Земле: самые сухие пояса у полюсов.
Ориентир 12.4 по зональному профилю — 0 из 16 в обоих режимах. Ориентир переписать
(см. [../PLAN.md](../PLAN.md), шаг 6).
