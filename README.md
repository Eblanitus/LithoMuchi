# Litospherity

Мод генерации мира для Minecraft Java Edition 26.3 на движке [Horizon](https://github.com/horizon-rust/horizon) (Minecraft, переписанный на Rust). Репозиторий: LithoMuchi.

## Идея

В ванильной генерации вода, суша и климат раскладываются случайными слоями шума. В Litospherity основа мира другая: **литосферные плиты**, случайные, но в рамках правдоподобия, как на настоящей Земле. Из плит выводятся материки, горы, океанские жёлоба и хребты, реки и влажность.

Температура от плит не зависит. Она задаётся положением относительно «солнца»: мир плоский, поэтому вместо двух полюсов у него много **полюсов-точек**. Вокруг каждого расходятся климатические пояса, которые сливаются в широкие экваториальные зоны. Влажность считается «по-умному»: пояс, постоянные ветры, дождевая тень за горами и то, откуда дует ветер, с океана или с материка.

Похожие моды обычно не пытаются в науку. Здесь правдоподобие это главная цель.

## Принципы

- **Бесконечный мир.** Всё считается локально по координатам и сиду, без глобальной симуляции.
- **Статичный мир.** Нет дрейфа плит, сезонов, смены уровня моря.
- **Плиты в основе:** горы на стыках, реки, биомы и влажность выводятся из них.
- **Только ванильное:** ванильные биомы и блоки. Пещеры не трогаем, кроме одного: глубинная лава тянется к стыкам плит.
- **Два режима**, выбираются при создании мира:
  - *геймплейный*: близко к ванили, с большими биомами;
  - *научный*: максимально правдоподобно и менее играбельно, например по 1000 блоков одного биома.
- **Rust.** Ядро генерации это отдельная библиотека без зависимостей от игры. Мод для Horizon, запасной вариант Fabric.

## Быстрый старт

```bash
# карта плит, стыков и диагностики искажения для сида 42
cargo run -p litho-sandbox --release -- render \
  --seed 42 --mode gameplay --layers all --size 512 --bpp 64 --out out/seed42

# все доступные поля в точке
cargo run -p litho-sandbox --release -- probe --seed 42 --mode scientific --at 1200,-3400

# таблица параметров и их хэши
cargo run -p xtask -- params-doc
cargo run -p xtask -- params-hash

# рабочая версия Э3.5; синтетика только для smoke, не для приёмки
cargo run -p litho-sandbox --release -- stats   --seed 42 --mode gameplay --version v1-dev --synthetic-height --size 64
# T110–T122: диагностика стока, русел, озёр, рельефа и морфозон в v1-dev
cargo run -p litho-sandbox --release -- drainage --seed 42 --mode gameplay --version v1-dev --at 0,0
cargo run -p xtask -- params-doc --version v1-dev
```

Таблица всех чисел генератора с хэшами режимов: замороженная v0 — [docs/PARAMS.md](docs/PARAMS.md), рабочая v1-dev — [docs/PARAMS-V1-DEV.md](docs/PARAMS-V1-DEV.md).

Масштаб: по умолчанию 16 блоков на пиксель в геймплейном режиме (обзор планеты — это 2048×2048 px). При `--size 512` ставьте `--bpp 64`, иначе получится крупный план в пару ячеек плит. Готовые картинки для оценки лежат в `docs/images/v0-seed42-gameplay/`.

У каждого PNG рядом лежит `.json` с сидом, режимом, версией, `params_hash`, масштабом и путём расчёта (подпись по 12.3). По умолчанию карты идут эталонным путём; `--path fast` переключает климатические слои на решётку и кэш — это ровно тот путь, который увидит игра.

Команды песочницы: `stats` (метрики 12.4 и границы T134), `seams` (скачки между соседними блоками), `drainage` (T110–T122, сток, расход, русла, озёра, дельты и рельеф в `v1-dev`), `bench` (время эталонного и быстрого пути), `checkpoints` (10 точек для сверки с игрой), `sweep` и `atlas` (16 сидов × 2 режима). Готовый [атлас](docs/images/atlas.html) лежит рядом с картами.

`litho-core` не имеет зависимостей; песочница и xtask пока тоже (свой минимальный PNG-кодировщик). CI собирает и сравнивает побитовые эталоны на Linux, Windows msvc и Windows gnu, отдельно проверяет MSRV 1.85.

1. Прочитайте [карту документации](docs/README.md) и

Для игры понадобится Horizon и лицензионная Minecraft Java Edition: Horizon берёт файлы игры из вашей копии.
